# ADR-0004：统一时间与展示回执

- 状态：Accepted
- 日期：2026-11-10
- 决策：领域注入同一 Clock。UTC 绝对时间保留用户时区标识，单调时间用于持续时长；FakeClock 驱动确定性回放。Qt 定时器仅 pump，不成为调度真相。
- 展示：请求、已渲染、用户响应、用户完成是四种事实。GUI 主线程在可见卡片绘制后发回执，稳定 delivery_id 支持重试去重；simulated/native/offscreen 明确标记。
- 结果：强提醒与软提醒最后兜底均不等待模型。缺回执不能写成已展示；用户点击完成才完成任务。暂停工作段保存剩余时长。
- 恢复边界：M0 不持久化任务。B 后续先保存投递意图、再显示、再落回执，通过同 ID 重试与 GUI 幂等恢复；不承诺跨崩溃严格 exactly-once。
