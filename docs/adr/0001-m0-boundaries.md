# ADR-0001：独立 M0 联调入口与所有权

- 状态：Accepted
- 日期：2026-11-10
- 背景：当前 Mochi 是单次宠物 Intent 闭环，新工作辅助架构包含任务、工具与交互确认。四人需要立即并行，不能等完整模型或后端。
- 决策：保留原桌宠产品入口；新增独立 M0 任务与工作段联调入口。主负责人维护公共契约、Runtime 和装配；B 拥有任务状态/SQLite/可靠调度；C 拥有正式动态 GUI 和工作段；D 拥有事件规范、评估、回放和报告。
- 结果：M0 使用有状态内存服务、固定 Qt 窗口和脚本决策。B/C/D 可以逐个替换自己的端口。A4 首版由主负责人提供既有采样适配和最小规则，D 负责误判与标注分析。
- 后续：SQLite、动态 renderer、真实 Jev/System 2 与完整研究报告分别交由对应工作包。
