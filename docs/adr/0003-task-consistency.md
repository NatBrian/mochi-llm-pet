# ADR-0003：任务状态单写与异步一致性

- 状态：Accepted
- 日期：2026-11-10
- 决策：TaskService 是任务变更唯一入口。命令使用 command_id 去重、expected_version 做比较；决策和工具另带任务版本、相关 context_revision 与期限。接受时和副作用前均校验。确认前草稿不调度。
- 线程：同步领域核心由服务所属线程调用；Qt 窗口通过 queued signal 请求，所有 QWidget 在 GUI 主线程。正式 SQLite 连接必须在服务线程创建，模型网络不占任务事件循环。
- 取消竞争：同服务内按确定的提交顺序裁决。取消撤销未执行工作；迟到结果拒绝。已经实际展示的历史不伪称回滚。高频观察可以合并，任务命令不得经过会丢事件的 debounce。
- 结果：B 实现持久事务时复用同一契约与行为测试；M0 内存单写证明语义，不能作为跨进程恢复证据。
